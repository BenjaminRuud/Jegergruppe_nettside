Jegergruppe Nettside

En nettside laget for en fiktiv jegergruppe. Nettsiden kombinerer informasjon om jakt med et enkelt skytespill og en funksjon for å registrere felte dyr.

Om prosjektet:
Nettsiden inneholder et skytespill hvor spilleren skal skyte på dyr som er lovlige å jakte på. Dyr som er fredet eller ikke er lovlige å skyte skal ikke skytes.
Nettsiden har også en registreringsfunksjon hvor brukeren kan registrere dyr som er felt under jakt.

Ved registrering oppgir brukeren blant annet:
* Hvilken dyreart som er skutt
* Antall hannkjønn
* Antall hunnkjønn
* Dato for jakten

Etter registreringen får brukeren en kvittering med informasjon om det som er registrert.

Funksjoner:
* 🦌 Skytespill med forskjellige dyrearter
* 📝 Registrering av felte dyr
* 🧾 Kvittering etter registrering

Teknologier:
* HTML
* CSS
* JavaScript


Hvordan kjøre prosjektet:

Last ned eller klon repositoryet og åpne prosjektmappen i VS Code.

For en enkel HTML/CSS/JavaScript-versjon kan nettsiden åpnes ved å starte `index.html` i nettleseren.
